# Grocery Store Prototype

A simple grocery store website prototype built with HTML, CSS, and JavaScript. The project includes multiple pages for home, about, contact, privacy, and terms, plus a Python file for additional functionality.

## Project structure

- `WebPrototype/`
  - `index.html` - Main homepage
  - `about.html` - About page
  - `contact.html` - Contact page
  - `privacy.html` - Privacy policy page
  - `terms.html` - Terms and conditions page
  - `EyeIconFunctionalityFix.html` - UI fix demo page
  - `script.js` - JavaScript for page interactions
  - `style.css` - Shared styling
  - `Grocery Store.py` - Python script included with the prototype
  - `README.md` - Project documentation for the web prototype

## Usage

1. Open `WebPrototype/index.html` in a web browser.
2. Use the navigation links to explore the available pages.
3. Inspect and edit `style.css` or `script.js` to customize the look and behavior.

## Notes

- This repository is a prototype and may include experimental or example code.
- The Python file is separate from the web pages and may require a Python interpreter to run.
